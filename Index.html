Materi Lengkap IP Address

Panduan mendalam mengenai Internet Protocol Address (IPv4 & IPv6), Struktur Network & Host ID, Kelas IP, Subnet Mask, hingga analogi Gen-Z.

Pengertian IP Address & Analogi Pos

IP Address (Internet Protocol Address) adalah alamat unik yang digunakan untuk mengidentifikasi setiap perangkat yang terhubung ke jaringan komputer atau internet, agar dapat saling mengirim dan menerima data.

Analogi Layanan Pos vs Paket Data

Seperti surat pos yang memerlukan Destination Address (Alamat Tujuan) dan Return Address (Alamat Pengirim/Source), paket data di internet juga membungkus Destination IP dan Source IP agar router tahu ke mana data harus dikirim dan bagaimana cara membalasnya.

Struktur IP Address

Terdiri dari dua bagian utama:

  • Network ID: Menunjukkan jaringan tempat perangkat berada.
  • Host ID: Menunjukkan perangkat spesifik di dalam jaringan tersebut.
Contoh: 192.168.10.1 → Network ID: 192.168.10 | Host ID: 1

Versi IP Address (IPv4 vs IPv6)

IPv4 32 Bit

Internet Protocol version 4

Format: 4 kelompok angka desimal (0–255) dipisah titik.

Contoh: 192.168.1.1 (Kapasitas ±4,3 miliar alamat)
IPv6 128 Bit

Internet Protocol version 6

Format: 8 kelompok heksadesimal dipisah titik dua.

Contoh: 2001:0db8::8a2e:0370:7334 (Kapasitas hampir tak terbatas)

Struktur Biner IPv4 (32-bit)

32 bit dibagi menjadi 4 bagian (oktet), masing-masing terdiri dari 8 bit yang dikonversi ke desimal:

10000011
→ 131 (8 bit)
01101100
→ 108 (8 bit)
01111010
→ 122 (8 bit)
11001100
→ 204 (8 bit)

Kelas IP Address (IPv4) & Subnet Mask

IPv4 dibagi ke dalam beberapa kelas (A, B, C, D, E) untuk mengelompokkan skala jaringan, mulai dari jaringan berskala besar (ISP/pemerintahan) hingga jaringan rumah kecil.

Kelas Rentang IP Network ID Host ID Maks. Host Contoh Penggunaan
A 1.0.0.0 – 126.255.255.255 8 bit 24 bit ±16 Juta Jaringan besar (ISP, Pemerintahan)
B 128.0.0.0 – 191.255.255.255 16 bit 16 bit ±65 Ribu Kampus, Organisasi Besar
C 192.0.0.0 – 223.255.255.255 24 bit 8 bit ±254 Kantor Kecil, Rumah
D 224.0.0.0 – 239.255.255.255 Multicast (Tanpa Host ID) Streaming, Siaran
E 240.0.0.0 – 255.255.255.255 Eksperimen / Riset Riset & Pengembangan

Subnet Mask (Pelengkap Struktur IP)

Subnet Mask digunakan untuk memisahkan bagian Network ID dan Host ID secara pasti.

IP Address  : 192.168.1.10
Subnet Mask : 255.255.255.0
255 = Bagian Network
0 = Bagian Perangkat (Host)

IP Address: Public vs Private & Analogi Gen-Z

Perbedaan mendasar antara alamat yang hanya bisa diakses dalam jaringan lokal (Private) dengan alamat global yang dapat diakses di seluruh internet (Public).

IP Private

Si Anak Rumahan / Introvert

"Aku sih nyaman di rumah aja, bro. Dunia luar terlalu ramai." — Kata Private IP sambil rebahan di jaringan LAN.

  • Fungsi: Nomor kamar atau nomor rumah di dalam kompleks perumahan lokal (WiFi/LAN).
  • Rentang Khusus:
    • 192.168.0.0 – 192.168.255.255 (Rumahan)
    • 10.0.0.0 – 10.255.255.255 (Perusahaan Besar)
    • 172.16.0.0 – 172.31.255.255 (Perusahaan Menengah)

IP Public

Si Selebgram Dunia Maya

"Follow aku dong, aku ada di 103.45.78.22. Jangan lupa like dan ping ya~" — Kata Public IP di server global.

  • Fungsi: Diberikan oleh ISP (Telkom, Indihome, dll) sebagai identitas unik global di internet.
  • Karakteristik: Bisa dilihat semua situs web yang kamu kunjungi, namun rentan terhadap ancaman luar jika tidak diamankan.

IP Dynamic vs Static

Perbedaan metode alokasi alamat IP pada perangkat atau server router Anda.

IP Dynamic

Alamat IP yang berubah-ubah secara periodik. Setiap kali router menyala ulang atau setelah waktu tertentu, ISP memberikan IP Public baru.

Keuntungan: Lebih hemat biaya & aman untuk rumah.
Contoh: Hari ini 180.241.123.45, besok bisa berubah menjadi 180.241.124.100.

IP Static

Alamat IP yang tetap dan tidak pernah berubah, sangat cocok untuk server, website instansi, atau CCTV yang harus selalu ditemukan di alamat yang sama.

Kelebihan/Kekurangan: Konsisten dan mudah ditemukan, namun berbayar dan rentan serangan karena alamatnya tetap.
Contoh: Server kementerian.go.id memiliki IP Static khusus.
